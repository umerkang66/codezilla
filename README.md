# ⚡ Codezilla Technologies

> Next-generation corporate agency website & content management system built with Next.js 16, React 19, TailwindCSS v4, and Supabase.

---

## ✨ Features

- 🚀 **Next.js 16 App Router**: Server-rendered React 19 architecture with optimal performance and SEO.
- 🛡️ **Role-Based Access Control**: Secure RBAC powered by Supabase Auth and Row Level Security (RLS).
- 🎨 **Modern Design System**: Sleek glassmorphism theme, fluid Framer Motion animations, and responsive layout.
- 💼 **Complete Agency Suite**: Portfolios, services, team showcases, testimonials, blogs, and career portals.
- ⚙️ **Comprehensive Admin CMS**: Centralized admin panel for real-time blog creation, message processing, and job application management.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Frontend**: React 19, TailwindCSS v4, Framer Motion, Lucide Icons
- **Backend / Database**: Supabase PostgreSQL, `@supabase/server`, `@supabase/ssr`
- **Language**: TypeScript 5

---

## ⚡ Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/umerkang66/codezilla-website.git
cd codezilla-website

# 2. Install dependencies
npm install

# 3. Provision environment variables
cp .env.example .env

# 4. Start local development server
npm run dev
```

Visit [`http://localhost:3000`](http://localhost:3000) in your browser.
